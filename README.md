# 📩 Task 20 – Newsletter Signup Modal

A modern and responsive **Newsletter Signup Modal** built using **HTML5, CSS3, and JavaScript** as part of my Veda Technology internship task.

The project displays an attractive newsletter subscription popup that automatically appears after a few seconds and allows users to subscribe using their email address.

## 📌 Project Overview

The Newsletter Signup Modal is designed to encourage website visitors to subscribe to a newsletter.

The modal includes:

- Automatic popup after 3 seconds
- Email input field
- Email validation
- Subscribe button
- Close button
- Overlay click to close
- Escape key support
- Success message after subscription
- LocalStorage functionality
- Responsive design for mobile and desktop

---

## ✨ Features

### 📩 Newsletter Modal
An attractive modal popup for newsletter subscriptions.

### ⏱️ Automatic Display
The modal automatically appears **3 seconds after the page loads**.

### 📧 Email Validation
The application checks whether the entered email address is valid.

### ❌ Multiple Close Options
Users can close the modal using:

- Close (×) button
- Clicking outside the modal
- `Escape` key

### ✅ Success Message
After entering a valid email address, a success message is displayed.

### 💾 LocalStorage
The application uses `localStorage` to remember that the user has already closed or submitted the newsletter form.

### 📱 Responsive Design
The interface works smoothly on:

- Desktop
- Laptop
- Tablet
- Mobile devices

---

## 🛠️ Technologies Used

- **HTML5** – Structure and content
- **CSS3** – Styling, animations and responsive design
- **JavaScript** – Modal functionality and form validation
- **LocalStorage** – Stores newsletter modal state
